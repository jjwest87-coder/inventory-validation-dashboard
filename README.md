# 재고 파악 대시보드 (Inventory Validation Dashboard)

품목별 담당자가 매월 실사 재고 수량을 입력하면, 이전 재고 · 입고 수량 · 과거 평균 출고량을 기준으로
예상 재고 수량을 계산해 실사 입력값이 크게 벗어나는지 자동으로 확인해주는 내부용 대시보드입니다.

## 실행 방법

이 폴더는 네트워크 공유 경로(UNC)에 있습니다. Node.js 빌드 도구는 UNC 경로를 작업 디렉터리로
직접 사용할 수 없으므로, PowerShell에서 드라이브 문자로 매핑한 뒤 실행하세요 (한 번만 설정하면
재부팅 후에도 유지됩니다):

```powershell
net use Z: "\\10.10.50.131\0.분자진단학부\10.담당자폴더\1.김지정" /persistent:yes
Set-Location "Z:\9.inventory-validation-dashboard"

npm install
npm run db:seed     # 품목/담당자/과거 출고량 데이터 가져오기 (최초 1회, DB 스키마도 자동 생성됨)
npm run dev
```

브라우저에서 http://localhost:3000 접속. (같은 사내망의 다른 PC에서 접속하려면 이 PC가 켜져 있고
`npm run dev`가 실행 중이어야 하며, `http://<이 PC의 사내 IP>:3000`으로 접속합니다.)

- 로그인: 사번 (예: `L20111`) / 초기 비밀번호 `1111`
- 마스터 계정: `L20111` (담당자 추가, 품목 추가·담당자 변경, 품목 비활성화/삭제, 입고처 등록 가능)

## 메인 화면 사용법

- 기본적으로 **전체 품목**이 보이며, 상단 필터에서 연도·월(1~12월, 연도는 자동으로 전년~내후년까지
  선택 가능)과 담당자(전체 또는 특정 담당자)를 선택해 원하는 시점·담당자 기준으로 다시 조회할 수
  있습니다.
- 각 행에는 지난달 실사 수량이 참고용으로 함께 표시됩니다. **이번달 입고 수량은 직접 입력하지 않고,
  입고 관리 화면에 기록된 값이 자동으로 반영**됩니다 — 실사 담당자는 실사 수량만 입력하면 됩니다.
- 여러 품목의 실사 수량(및 다음달 발주 수량)을 입력한 뒤, **"전체 저장" 버튼 한 번으로 한꺼번에
  저장**합니다. 품목마다 따로 저장 버튼을 누를 필요가 없습니다.
- 담당자가 재고 파악 당일 자리를 비웠다면, 로그인한 다른 누구나 그 품목의 수량을 대신 입력할 수
  있습니다. 저장된 값 옆에 실제로 입력한 사람 이름이 "입력: 홍길동" 형태로 함께 기록되어 나중에
  확인할 수 있습니다.
- 재고 파악과 같은 화면에서, 그 자리에서 다음달 발주 수량도 함께 입력해 같은 "전체 저장"으로 저장할
  수 있습니다 (예: 8월 실사를 하면서 9월 발주 수량을 함께 입력).
- 실사 수량이나 발주 수량을 나중에 다른 값으로 정정하면, 셀 아래에 "수정: 이전값 → 새값 (수정한
  사람)" 형태로 정정 이력이 남습니다. 원래 담당자가 실사한 값과 다르게 입력해야 하는 경우에도
  그 변경 내역이 그대로 보존됩니다.
- 품목명에 마우스를 올리면 제조사가 툴팁으로 표시됩니다. 행마다 배경이 옅게 번갈아 표시되고,
  실사 수량 입력칸은 파란색으로 구분되어 있어 폭이 넓은 표에서도 품목명과 입력칸을 쉽게 짝지어
  찾을 수 있습니다.
- 실사 수량·다음달 발주 수량 입력칸은 **키보드로만 값을 바꿀 수 있습니다** — 마우스 스크롤을 올리는
  중 칸 위를 지나가도 숫자가 바뀌지 않고, 증감 화살표 버튼도 없습니다.
- 품목마다 **발주 단위(배수)**를 지정해둘 수 있습니다 (관리자 화면 → 품목 관리 → "발주 단위" 칸).
  배수에 맞지 않는 값을 입력하면 발주 입력칸이 빨간색으로 표시되고 경고 문구가 뜹니다 (저장을 막지는
  않으며, 다시 확인하라는 안내입니다). 지정하지 않은 품목은 검증하지 않습니다.

### 목록 인쇄

담당자를 선택한 뒤 "목록 인쇄"를 누르면, 실제 재고 실사 현장에 들고 나갈 수 있는 종이 양식으로
출력됩니다.

- 화면의 제목/필터/버튼/입고관리·관리자화면·로그아웃 메뉴는 인쇄에서 모두 빠지고, 대신 맨 위에
  "2026년 9월 재고실사 홍길동 품목 12건"처럼 연도·월·담당자·품목 수가 한 줄 제목으로 표시됩니다.
- 인쇄 열은 품목코드·품목명·지난달 실사·이번달 입고·이번달 실사·다음달 발주만 남고(규격·담당자·
  예상수량·판정 열은 제외), 품목명이 길면 잘려서 한 줄로 유지됩니다.
- 품목에 등록해둔 **비고(빨간 글씨)는 품목명 아래에 그대로 인쇄**되어, 현장에서 실사할 때 특이사항을
  바로 확인할 수 있습니다.
- **"이번달 실사" 칸은 화면에 입력해둔 값과 상관없이 항상 빈 칸(테두리 상자)으로 인쇄**됩니다 —
  현장에서 수기로 적어올 수 있도록 하기 위함입니다.
- 글자 크기와 여백을 줄여 한 페이지 안에 최대한 맞춰지도록 했습니다 (품목 수가 아주 많으면 브라우저
  인쇄 미리보기에서 "맞춤/축소" 배율을 조정해야 할 수 있습니다).

## 입고 관리 (발주 · 입고 화면)

대시보드 상단의 "입고 관리" 메뉴에서 특정 월에 발주된 전체 품목을 표 한 줄에 하나씩, 담당자 구분
없이 전체 목록으로 모아 볼 수 있습니다.

- 발주 수량 옆에 **누적 입고 수량이 항상 그대로 표시**됩니다 (예: 발주 8개를 8개 입고 처리하면
  저장 후 다시 봐도 "입고 8, 미입고 0"으로 남아 있습니다). 그 아래 입력칸은 이후에 추가로 들어오는
  물량을 더할 때만 사용합니다.
- 입고일·추가 입고 수량·명세서 동봉 여부를 입력한 뒤, **"전체 저장" 버튼 한 번으로 한꺼번에** 등록합니다
  (품목마다 여러 번 입고될 수 있어 나눠 등록해도 누적됩니다).
- 여기에 기록한 입고 수량은 재고 파악 대시보드의 "이번달 입고(자동)" 값으로 바로 연결되어, 같은
  숫자를 두 번 입력할 필요가 없습니다.
- 체크박스로 여러 품목을 선택하면 해당 행이 색으로 표시되고, 상단의 **"입고일 일괄 적용"**과
  **"명세서 일괄 적용"**으로 선택한 품목 전체에 같은 입고일 또는 명세서 체크/해제를 한 번에 적용할
  수 있습니다 (그중 일부만 실제로 다르면 개별 행에서 따로 조정하면 됩니다).
- **"선택 항목 전량 입고"** 버튼을 누르면, 체크한 품목들의 입고 입력칸에 각자의 남은 수량(발주 −
  누적입고)이 자동으로 채워집니다. 발주한 만큼 전부 들어온 경우 일일이 수량을 계산해 입력할 필요
  없이 한 번에 처리할 수 있습니다.
- 발주 수량보다 입고 수량을 더 많이 입력해서 저장하면 상태가 **"초과입고 확인필요"**로 빨간색
  표시되고, 미입고 칸도 음수(예: -3)로 빨간색 표시되어 바로 눈에 띕니다.
- **"입고처" 필터**와 **"상태" 필터**(전체/미입고/부분입고/입고완료/초과입고)를 함께 쓸 수 있어, 예를 들어
  "이 업체의 미입고 품목만" 처럼 좁혀서 볼 수 있습니다. 필터가 걸린 상태에서 헤더의 전체선택
  체크박스를 누르면 그 조건에 맞는 품목만 한 번에 선택됩니다. 품목별 입고처는 관리자 화면에서
  미리 등록·지정합니다.
- "입고일" 열 헤더를 클릭하면 입고일 기준으로 오름차순/내림차순 정렬됩니다.
- 입고처마다 지정한 색상이 목록에서 옅은 배경색으로 표시되어, 같은 업체 품목을 필터 없이도 한눈에
  구분할 수 있습니다.
- 나눠 입고된 품목은 "입고 이력 N건 보기"를 눌러 **각 입고 건의 날짜·수량·명세서 여부를 모두
  확인**할 수 있고, 잘못 입력된 건은 그 자리에서 **수정**하거나 **삭제**할 수 있습니다 (수정·삭제
  시 발주 대비 누적 입고·미입고·상태가 자동으로 다시 계산됩니다).
- 재료명 아래에 제조사가 작게 함께 표시되어, 이름이 비슷한 품목도 구분하기 쉽습니다.

## 관리자 화면 — 품목 관리

- 품목 목록에 제조사 열이 추가되어 있습니다 (원본 엑셀에서 가져온 값이며, 관리자가 필요 시 데이터를
  갱신할 수 있습니다).
- **"발주 단위"** 칸에 숫자를 입력하면 그 품목은 해당 배수로만 발주할 수 있도록 재고 파악 화면에서
  검증됩니다 (예: 2를 넣으면 짝수만 허용). 빈 칸으로 두면 검증하지 않습니다. 추가·삭제·변경 모두
  이 칸에서 바로 처리합니다.
- **"비고"** 칸에 특이사항을 적어두면, 재고 파악 대시보드의 품목명 바로 아래에 작은 빨간 글씨로
  표시되어 실사 시 바로 눈에 띕니다 (예: "유효기간 임박", "포장 단위 변경됨"). 입력 후 다른 곳을
  클릭하면 자동 저장되고, 비워두면 표시되지 않습니다.

- 각 품목마다 **비활성화/복원** 버튼으로 목록에서 숨기거나 다시 보이게 할 수 있고(실사·발주 이력은
  그대로 보존됩니다), **삭제** 버튼으로 완전히 제거할 수 있습니다.
- 단, 실사·발주·출고 이력이 하나라도 있는 품목은 데이터 보존을 위해 완전 삭제가 되지 않고
  "비활성화"만 가능합니다 (삭제를 시도하면 안내 메시지가 표시됩니다). 이력이 전혀 없는 품목(예:
  잘못 등록한 경우)만 완전히 삭제할 수 있습니다.
- "비활성 품목 포함" 체크박스로 비활성화된 품목도 목록에서 확인하고 필요하면 복원할 수 있습니다.

## 관리자 화면 — 입고처 관리

- 입고처 등록 시 색상을 지정할 수 있고, 등록 후에도 색상·담당자·전화번호를 표에서 바로 수정할 수
  있습니다 (담당자/전화번호 칸은 입력 후 다른 곳을 클릭하면 자동 저장됩니다).

## 관리자 화면 — LOT 목록 관리 (LOT별 실사)

MD/MR 계열 시약처럼 한 품목에 LOT이 여러 개 동시에 있는 경우, LOT별로 따로 실사해서 합계를 그
품목의 이번달 실사 수량으로 반영할 수 있습니다.

- 관리자 화면 하단 "LOT 목록 관리"에서 먼저 **적용할 연도·월을 선택**한 뒤, **엑셀에서
  품목코드·LOT번호 두 열을 그대로 복사해 붙여넣고** "일괄 등록"을 누르면, 그 품목들의 **그 달**
  LOT 목록이 통째로 교체됩니다. LOT은 매달 구성이 바뀌므로 월별로 따로 관리되며, 한 달의 목록을
  등록해도 다른 달의 목록에는 영향을 주지 않습니다. 새로 들어온 LOT은 추가되고, 이번에 빠진 기존
  LOT은 그 달 목록에서만 제외됩니다 (과거 실사 기록은 삭제되지 않고 그대로 남습니다). 다음 달 LOT
  구성이 바뀌면 월 선택을 바꾼 뒤 그 달 목록을 붙여넣으면 됩니다.
- LOT이 등록된 품목은 재고 파악 대시보드의 "이번달 실사" 칸이 **LOT별 입력칸 여러 개 + 합계**로
  바뀝니다. 각 LOT 수량을 적으면 합계가 자동 계산되고, "전체 저장"을 누르면 그 합계가 품목의
  이번달 실사 수량으로 저장되어 예상 재고 비교·판정·수정 이력 등 기존 기능이 그대로 적용됩니다.
- 목록 인쇄 시에도 LOT 번호마다 손으로 쓸 수 있는 빈 칸이 각각 인쇄됩니다.

## 데이터 소스

`data/raw/` 폴더의 두 원본 엑셀 파일을 `npm run db:seed` 실행 시 가져옵니다.

- `품목별 담당자.xlsx` — 품목 목록 및 담당자
- `품목별 사용량 추이 조회.xlsx` — 2026년 1~8월 월별 출고량 (평균 계산의 기준 데이터)

9월부터는 대시보드에서 직접 입력한 실사 수량이 다음 달 예상 수량 계산에 자동으로 누적됩니다.

## 재고 이상 판정 로직

특정 품목의 이번 달 예상 재고 = 지난달 실사 재고 + 이번 달 입고 수량 − 최근 3개월 평균 출고량

실사 입력값이 예상 재고와 `max(2개, 평균 출고량의 30%)` 이상 차이 나면 "확인필요"로 표시됩니다.
(첫 입력 달은 비교할 지난달 데이터가 없어 "기준월"로 표시되고 검증은 다음 달부터 시작됩니다.)

추가로, **이번달 입고가 0인데 실사 수량이 지난달보다 늘어난 경우**는 위 오차 범위 안에 들더라도
무조건 "확인필요 (입고 없이 증가)"로 표시됩니다 — 입고 없이 재고가 늘어나는 것은 물리적으로
불가능하므로, 일반적인 오차 허용 범위와 별개로 항상 확인이 필요합니다.

## 데이터베이스

로컬 SQLite 파일(`db/dev.db`, Node.js 내장 `node:sqlite` 모듈 사용)을 사용합니다.
외부 클라우드 계정이 필요 없으며, 데이터는 이 폴더를 벗어나지 않습니다.
